# SecureAudit Lab (Proyecto de Programación Segura)

Plataforma web de auditoría de scripts de mitigación evaluados con la metodología STRIDE.

# Estructura del proyecto
- `backend/`: API, autenticación, base de datos y motor de auditoría.
- `frontend/`: plantillas HTML y archivos estáticos (css, js, img)
- `scenarios/`: escenarios STRIDE y scripts de prueba
- `docs/`: informe técnico con los DFDs y modelado STRIDE/DREAD
